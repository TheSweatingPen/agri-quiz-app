# Data Model (Database Tables)

We are using MySQL (XAMPP locally, PlanetScale in production) with Prisma ORM.

## 1. Users Table (`User`)
- `id` (String, Primary Key, UUID)
- `matricNo` (String, Unique - used for login)
- `email` (String, Unique)
- `passwordHash` (String)
- `firstName` (String)
- `lastName` (String)
- `role` (Enum: 'STUDENT', 'CLASS_REP', 'ADMIN')
- `xp` (Int, default 0 - for streak rewards)
- `currentStreak` (Int, default 0)
- `lastStreakDate` (DateTime)
- `classId` (String, Foreign Key)

## 2. Questions Table (`Question`)
- `id` (String, Primary Key)
- `text` (Text)
- `optionA` (String)
- `optionB` (String)
- `optionC` (String)
- `optionD` (String)
- `correctOption` (String - e.g., "A")
- `topic` (String - e.g., "Crop Science", "Soil Science")
- `createdById` (String, Foreign Key -> User)

## 3. Quizzes Table (`Quiz`)
- `id` (String, Primary Key)
- `title` (String)
- `description` (String)
- `timeLimit` (Int - in minutes)
- `createdById` (String, Foreign Key -> User)
- `createdAt` (DateTime)

## 4. Quiz Attempts Table (`QuizAttempt`)
(Used for tracking analytics and rankings)
- `id` (String, Primary Key)
- `userId` (String, Foreign Key -> User)
- `quizId` (String, Foreign Key -> Quiz)
- `score` (Int)
- `totalQuestions` (Int)
- `timeTaken` (Int - in seconds)
- `completedAt` (DateTime)

## 5. Answers Table (`AttemptAnswer`)
(Used to calculate what topics a student is weak in)
- `id` (String, Primary Key)
- `attemptId` (String, Foreign Key -> QuizAttempt)
- `questionId` (String, Foreign Key -> Question)
- `selectedOption` (String)
- `isCorrect` (Boolean)
