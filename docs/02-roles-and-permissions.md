# Roles & Permissions

## 1. Student
- Register (matric, email, reg number — matric is unique key)
- Take quizzes from past questions
- View own analytics (accuracy, weak topics, streak, rank)
- Earn daily streak reward

## 2. Class Rep
- Approve/verify student registrations for their class
- Add/edit questions (scoped to their class/department)
- View class analytics (participation, averages, leaderboard)
- Post announcements to their class
- Trigger/assign quizzes to their class

## 3. Admin (Creator)
- Full CRUD: students, questions, quizzes, rewards, announcements
- Manage roles (promote student → class rep)
- View all analytics across classes
- Configure streak reward rules
- Override any class rep action
